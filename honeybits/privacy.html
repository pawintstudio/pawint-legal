Pawint Studio(이하 "회사")는 모바일 게임 HoneyBits(허니비츠)(이하 "게임")를 이용하는 분의 개인정보를 소중히 다루며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 이 방침은 게임이 어떤 정보를 어떤 목적으로 처리하는지, 누구와 공유하는지, 이용자가 어떤 권리를 가지는지 설명합니다.

요약: Android에서는 Google Play Games 로그인이 필요하며, 게임 자체에서 이름·이메일·전화번호·정확한 위치·연락처 입력을 요구하지 않습니다. 게임 진행을 저장하기 위한 게임 플레이어 ID와, 광고 제공을 위한 광고 ID·기기 정보 등이 자동으로 처리됩니다.

Google Play Games 로그인 시 플랫폼 플레이어 식별자와 인증 증명을 Unity Authentication으로 전달합니다. 해당 로그인에 연결된 게임 계정으로 진행 상황과 구매 내역을 저장하고 불러옵니다.

2. 처리 목적

  • 게임 제공: 진행 상황·코인·부스터 저장과 불러오기, 일일 보상 지급

  • 문의 응대: 이메일 문의에 대한 답변과 삭제 요청 처리

6. 광고 ID와 맞춤형 광고 (행태정보)

게임은 광고 ID와 앱 사용 기록을 광고 사업자가 수집하도록 허용하며, 이 정보는 맞춤형 광고와 광고 성과 측정에 쓰일 수 있습니다. 게임은 웹 쿠키를 사용하지 않습니다.

  • 광고 ID 삭제·재설정: Android 설정 → Google → 광고에서 "광고 ID 삭제" 또는 "광고 ID 재설정"
  • 광고 ID를 삭제해도 광고는 표시되지만, 맞춤형이 아닌 광고가 표시됩니다.
  • 유럽경제지역(EEA)·영국·스위스에서는 광고를 요청하기 전에 Google User Messaging Platform(Google 인증 동의 관리 플랫폼)이 제공하는 동의 양식을 보여 줍니다. 양식에는 광고 파트너(Google, Unity Ads, ironSource)가 나오며, 모두 동의·거부하거나 목적별로 고를 수 있습니다. 거부하거나 답하지 않으면 맞춤형이 아닌 광고가 표시됩니다. 고른 뒤에도 게임의 설정 → 맞춤 광고에서 양식을 다시 열어 언제든 바꿀 수 있습니다.
  • 인앱 상품 "광고 제거"를 구매하면 배너·전면 광고가 표시되지 않습니다. 보상형 광고는 유지되며, 광고 시청 후 보상이 지급됩니다. 광고 제거 구매 후에도 보상형 광고 제공을 위해 광고 SDK를 초기화합니다.

7. 이용자의 권리와 삭제 요청 방법

이용자는 언제든지 자신의 정보에 대한 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 삭제 방법은 두 가지이며, 자세한 안내는 계정 및 데이터 삭제 페이지에 있습니다.

게임 안에서 바로 삭제

  1. 게임의 설정 화면 맨 아래 계정 삭제를 누릅니다.
  2. 확인 창에서 삭제하기를 누르면 서버의 게임 계정과 게임 진행 데이터(진행, 코인, 부스터, 스킨)가 즉시 삭제되고, 기기에 저장된 게임 데이터도 함께 지워집니다.

인터넷에 연결되어 있어야 합니다. 삭제 뒤 다시 로그인하면 새 게임 계정으로 처음부터 시작합니다. 게임 계정 삭제는 Google 계정 자체를 삭제하지 않습니다.

이메일로 요청

  1. 게임의 설정 화면에서 플레이어 ID를 확인합니다.
  2. pawintstudio@gmail.com 로 제목 "데이터 삭제 요청", 본문에 플레이어 ID를 적어 보냅니다.
  3. 회사는 확인 후 30일 이내에 해당 플레이어 ID의 서버 데이터(게임 진행, 코인, 부스터)를 삭제하고 결과를 회신합니다. 법령상 보관 의무가 있는 결제 기록은 해당 기간 동안 분리 보관 후 파기합니다.

삭제하면 진행 상황과 보유 코인·부스터는 복구할 수 없습니다. 기기에 남은 데이터는 앱을 삭제하면 지워집니다. 광고 사업자가 수집한 정보는 광고 ID 삭제·재설정으로 연결을 끊을 수 있으며, 각 사업자에게 직접 요청할 수도 있습니다.

만 14세 미만 아동의 법정대리인도 위 방법으로 아동 정보의 열람·삭제를 요청할 수 있습니다.
